## 定时任务
DSH 远程插件目前没有调度相关能力（`agent/src/bridge` 中无 cron/schedule；DSH sessionController 方法列表也没有调度入口，见 `android-l1-probe-2026-10-24.md`）。因此做成设计完整的“即将推出”页：说明卡（为什么还不能用）、两张“示例”定时任务卡（时间 / 内容 / 设备）、功能清单（cron、通知、运行记录），以及“现在先用对话完成一次性任务”按钮跳回对话。后端开放后，示例卡直接替换为真实列表。

## 发现
- **快捷任务**（真实可用）：6 个常用提示，点击即新建任务并填入输入框，发给电脑上的 DSH。
- **电脑的能力**（真实数据）：当前设备 `capabilities` 列表，中文名 chip，可刷新。
- **技能与插件**：即将开放说明（插件尚未暴露 DSH 技能/插件目录）。

## 新增 Agent 能力（需重新部署插件）
`chat.session.rename`（sessionId, title）、`chat.session.delete`（sessionId），映射 DSH `sessionController.rename / delete`；插件版本 0.2.1。请求参数形状按探测到的方法名推断，尚未在真机 DSH 上验证。App 按能力目录显示菜单，旧插件不受影响。
